# Old build notes

These notes describe Demented Monkey's original exe server and the MSFS Project Editor package under `src/`. This fork does not build that way.

The package that ships is `1 - Src/z-DementedMonkey-LiM-CDU`. From the repository root:

```bash
npm install
npm run server
npm run build
npm run release
```

See `0 - DocsFolder/BUILD-PIPELINE.md`. There is no `cj4-mcdu-server.exe` and no Project Editor step.
